# AGENTS.md

This repository has two guidance files. Read both before changing anything:

1. [CLAUDE.md](CLAUDE.md) covers where the work stands, how to pick up the next issue (respecting **Blocked by**), the commands, the architecture, the decisions already made, and the rule that README.md always shows the current interface.
2. [CONVENTIONS.md](CONVENTIONS.md) covers how code is written: JavaScript with JSDoc (no TypeScript), Svelte 5 component structure, BEM classes with the `rg-` prefix, `{action}Handler` and `on{ComponentName}{Action}` naming, `ComponentEvent`, the rules-engine rules, tests and commits.

Keep guidance in those two files rather than here, so nothing drifts apart.
