# Deprecated player tokens

The flat five-colour token artwork was replaced on 2026-10-24 by the owner-supplied shaded 32×32 versions. These files are historical references and are excluded from the active catalog and build. Active stable URLs remain `piece/token-{blue,red,green,yellow,purple}`. Exact PNG sources are in `art/imported-pngs/player-tokens/`. The neutral `piece/token` is a separate unassigned-piece illustration, not a player-colour alternative.
