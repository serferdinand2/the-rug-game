# Archived owner review · 2026-10-23

The complete issue #5 mockup and its linked capital terrain page are frozen here. Open `index.html` directly, or browse this folder with the Vite dev server. All SVG pictures are embedded, so the snapshot does not depend on the current toolkit or generated assets. The five player-color buttons remain interactive.

The dice faces, terrain hex markers and game symbols shown here are historical placeholders, not approved production assets. See [the release notes](../../issue-5.md) for their intended text rendering and later artwork. The reviewed production art is in `static/art/`; editable vector drawing sources are in `art/drawings/`.

The six full capital mat SVGs are examples only. Actual capital mats must be generated from the reusable terrain tiles for each game, following the game setup and the rules-defined plot layout.
