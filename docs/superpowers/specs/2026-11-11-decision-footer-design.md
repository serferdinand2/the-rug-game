# Decision footer (#71)

When a decision is open, the panel owns the question. The turn footer names the actual public cause using the same reusable, styled source display as the panel; if no cause is known it gives the turn context instead. An income turn keeps its turn number and step without repeating the question. When a decision is minimized, its question stays in the footer with Show choice, as required by #149. No private card identity is added to a player's view.

The TurnBar library shows the decision and income states for review. The README shows a current component capture; production screenshots remain explicitly identified as historical when they have not been recaptured.
